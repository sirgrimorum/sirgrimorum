# Compliance Map

## Canonical Rule

- `AGENTS.md` is source of truth.
- Agent-specific files are adapters with only tool-specific highlights.

## Governed Layers

1. Canonical governance + architecture docs
2. Agent-agnostic rules and hook scripts
3. Agent-specific adapters
4. Planning and PR-draft conventions

## Adapt vs Upgrade

- Adapt: contextual compliance alignment, preserve existing project specifics.
- Upgrade: intentional governance model refresh to latest pattern set.

## Finalize Scope

Focus on files related to the current change and governance integrity; avoid full-repo rewrites.
