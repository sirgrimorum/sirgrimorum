# Planning Folder

Use this directory as execution source of truth.

## Planning Model

1. Feature plans: what new thing users can do.
2. Foundation plans: what new capability the codebase gains.

## Rules

1. Create/update plan files before implementation.
2. Keep status current while implementing.
3. Include E2E criteria for each plan item.
4. Reference plan updates in PR drafts.

Suggested files:

- `feature-roadmap.md`
- `foundation-roadmap.md`
- `architecture-plan.md`
- `release-plan.md`
